# This tap has moved (archived)

The Pastu cask now lives in the main repository and is updated automatically with every release:

```bash
brew tap keremeersoy/pastu https://github.com/keremeersoy/pastu && brew trust keremeersoy/pastu && brew install --cask pastu
```

If you tapped this repository before, run `brew untap keremeersoy/pastu` first, then use the command above.
This repository holds only the old 0.1.1 cask and is no longer updated.

Pastu: https://github.com/keremeersoy/pastu
